Recommended existing/live database commands
php artisan migrate --force
php artisan db:seed --force
php artisan optimize:clear

Local development
php artisan migrate --seed
php artisan optimize:clear
php artisan serve

Do not use migrate:fresh on a live database unless you intentionally want to delete all existing data.

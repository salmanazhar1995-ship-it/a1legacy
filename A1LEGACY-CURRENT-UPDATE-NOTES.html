A1 Legacy — Navigation, Industries & Responsive Headings Update

This package keeps the existing CMS/SEO/media work and adds the requested frontend refinements.

  • Footer navigation: two-column button grid on desktop/tablet, with a one-column fallback only on very small phones.
  • Industries showcase: sidebar now shows industry names only, with a live search field above the industry list.
  • Industries showcase visual: the right-side image/animation block was removed from this section and the remaining content is centered.
  • Industries CTA: “Discuss your workflow” was removed from the showcase; the industry detail link remains.
  • Heading alignment: public page and section headings use centered alignment.
  • Single-line headings: public page/section headings use a responsive fitter that reduces font size as needed so headings remain on one line without desktop/tablet/mobile overflow.

Database migration: none required for these frontend changes.

Main files changed: resources/views/layouts/site.blade.php, resources/views/layouts/site-footer.blade.php, resources/views/site/sections/business-showcase.blade.php, plus heading-wrapper improvements in the hero, video, standard-content, CTA and contact section views.

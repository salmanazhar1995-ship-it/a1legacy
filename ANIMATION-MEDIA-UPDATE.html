Rules

IMAGE MODE
- JPG / PNG / WebP / AVIF
- Max 5 MB
- Image ALT text is required whenever an image is used
- Existing legacy images receive an editable ALT fallback during migration

HTML ANIMATION MODE
- .html / .htm only (TXT is not accepted)
- Max 5 MB
- An HTML animation is required when HTML Animation mode is selected
- Served through the existing /media route
- Rendered in a sandboxed iframe

NON-IMAGE UPLOADS
- Client Story MP4/WebM video upload remains a video field
- Industries CSV import remains a CSV field

Industries CSV

The package root contains INDUSTRIES-IMPORT-DEMO.csv. The admin Industries page also provides a downloadable full CSV template. Keep the exact header order. Repeat the main-industry values on each sub-industry row.

Deployment

php artisan migrate --force
php artisan optimize:clear
php artisan optimize
